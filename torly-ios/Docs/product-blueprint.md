# Torly: стартовая структура MVP

## Название-заглушка

**Torly**  
Короткое имя от "tor" / "תור" - очередь, запись, слот. Рабочий смысл: мастер за 5 минут получает ссылку для Instagram и WhatsApp.

## Целевая аудитория

- Барберы, парикмахеры, мастера ногтей, бровисты, косметологи, массажисты и частные мастера в странах, где WhatsApp является основным каналом общения.
- Небольшие студии на 1-5 специалистов, которым Calmark или похожие системы кажутся дорогими или перегруженными.
- Владелец часто ведет клиентов в WhatsApp, Instagram DM, заметках или Google Calendar и хочет простой порядок без сложной CRM.

## Обещание продукта

Настроить услуги, часы работы и публичную ссылку за 5 минут. Клиент выбирает услугу и свободное время, владелец видит запись в календаре, клиент получает WhatsApp-напоминание и подтверждает визит.

## Международный фундамент

Torly стартует просто, но сразу хранит данные так, чтобы продукт можно было продавать не только в Израиле.

- **Языки:** Hebrew и English на старте; интерфейс поддерживает RTL для Hebrew.
- **Валюты:** бизнес хранит `currency`, сервисы хранят цену в minor units; на старте `ILS`, дальше `USD`, `EUR`, `GBP`.
- **Страны:** бизнес хранит `country_code`, чтобы включать нужные валюты, телефоны, налоги и платежи.
- **Часовые пояса:** бизнес хранит IANA timezone, например `Asia/Jerusalem`; записи хранятся в UTC, показываются во времени бизнеса.
- **WhatsApp templates:** шаблоны отдельно по языку и событию: подтверждение, напоминание сегодня, отмена, перенос.
- **Stripe-ready платежи:** подписка хранит provider/customer/subscription ids; для Израиля можно позже добавить локального провайдера.
- **Международные номера:** телефоны хранятся в E.164, например `+972524441091`.

## Ключевой пользовательский сценарий

1. Владелец регистрируется по телефону или email.
2. Выбирает страну, язык бизнеса, валюту и часовой пояс.
3. Вводит название бизнеса, город, адрес/район и ссылку Instagram.
4. Добавляет 2-3 услуги: название, цена, длительность.
5. Отмечает рабочие часы и перерывы.
6. Получает ссылку вида `torly.app/barber-dizengoff`.
6. Клиент открывает ссылку, выбирает услугу, день, слот, имя и телефон.
7. Владелец видит запись в календаре.
8. В день визита система отправляет WhatsApp: подтвердить, перенести или отменить.
9. Владелец видит базовые цифры: записи, выручка, повторы, no-show.

## MVP-экраны и разделы

- **Регистрация владельца:** Apple/Google/phone/email, имя, тип аккаунта: бизнес, клиент или оба.
- **Первичная настройка бизнеса:** страна, язык, валюта, часовой пояс, название, категория, город.
- **Dashboard владельца:** сегодняшние записи, короткая ссылка, быстрый статус настройки.
- **Услуги и цены:** CRUD услуг, цена, длительность, активность.
- **Рабочие часы:** недельное расписание, выходные, простые перерывы.
- **Публичная страница записи:** выбор услуги, месяца, дня, слота, форма клиента, подтверждение.
- **Календарь записей:** месяц/день/список, статус записи, ручное добавление, live-обновления.
- **Карточки клиентов:** имя, телефон, история посещений, заметки, no-show.
- **Напоминания:** WhatsApp-шаблоны по языку, время отправки, статус доставки, кнопки подтверждения.
- **Базовая аналитика:** записи, выручка, загрузка, повторные клиенты, no-show.
- **Тариф и оплата:** 2 месяца бесплатно, затем основной тариф ₪39/месяц в Израиле; Stripe-ready для мира.

## Тарифы

- **Trial:** первые 2 месяца бесплатно.
- **Torly Pro:** ₪39/месяц в Израиле после trial.
- Позже для мира: локальные цены вроде `$9`, `€9`, `£8` без изменения продукта.
- Позже для студий: отдельный тариф с несколькими сотрудниками, филиалами и расширенной аналитикой.

## Технический план реализации

- **iPhone app:** SwiftUI, native iOS, Torly brand, роли бизнес/клиент.
- **Admin web позже:** React/Next.js только если понадобится для владельцев с компьютера.
- **Backend MVP:** Node.js API на Hetzner CX33.
- **Realtime:** Supabase Realtime/Postgres changes для календаря и защиты от двойной записи.
- **База данных:** Supabase Postgres для владельцев, бизнесов, услуг, клиентов, записей и подписок.
- **Аутентификация:** email magic link или OTP по телефону на следующем этапе.
- **Напоминания:** worker + очередь + WhatsApp Business API templates.
- **Оплата:** Stripe-ready subscriptions; израильский провайдер можно подключить позже при необходимости.
- **Локализация:** English + Hebrew RTL с первого коммерческого backend.
- **Телефоны:** хранение в E.164, UI форматирует номер по стране.
